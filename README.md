# 西貢區中學全景 2026

一個以官方數據為本的單頁網站，橫向比較西貢區（將軍澳、西貢市中心、坑口、調景嶺）26 間中學的：

- **中一收生數字**：自行分配學位、統一派位學額及合計（2026/27 學年）
- **各級班數**：中一至中六的班級結構與總班數
- **學校特色**：辦學宗旨、關注事項、語文政策、收生準則、課外活動
- **社交平台**：Facebook / Instagram / YouTube / 小紅書的官方連結
- **宣傳策略**：按渠道數目與內容形態歸類的四種典型

## 檔案結構

```
index.html          單頁網站（無需 build，直接開啟）
assets/style.css    樣式
assets/app.js       前端邏輯：排序、篩選、圖表、詳情卡
assets/data.js      26 間學校的整理數據（window.SCHOOLS）
data/schools.csv    同一份數據的 CSV 版本，方便再分析
```

## 資料來源

| 項目 | 來源 |
| --- | --- |
| 學校名單、班級結構、辦學宗旨、收生準則、語文政策 | 家校會《中學概覽 2025/2026》 |
| 中一學額（自行分配＋統一派位，含直屬／聯繫學額） | 教育局《2024/2026 中學學位分配辦法——中學一覽表（西貢區）》、《2026 年度中一自行分配學位手冊》 |
| 社交平台連結 | 各校官方網站（2026-11-01 擷取）；官網未列出者以公開搜尋結果補充 |

## 使用限制

1. 中一學額未計留班位及後補／叩門取錄，與最終入學人數可能略有差異。
2. 7 間直資學校自訂收生、不參與統一派位，沒有統一中一學額公布，網站只列班數，不作推算。
3. 社交平台以官網連結為主要證據；部分帳號由學生組織或校友會營運，已在介面另行標示。
4. 「宣傳型態」是基於公開渠道的觀察與歸類，並非學校官方策略文件。
